# Database

This site uses the shared Supabase project `upzkvszgoqhoefkiwoep`, which also
backs farirainandipa.co.zw. The schema, seed data and migrations are kept in
the **farirainandipa-web** repository under `supabase/migrations/`.

Add new migrations there (next number, never edit old ones), apply them to the
project, then run the Supabase security advisor. See CLAUDE.md for the access
model.
